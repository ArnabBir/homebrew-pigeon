## Pigeon v1.0.0

### Features
- Full API testing support (HTTP, WebSocket, TCP, UDP, SSE, GraphQL)
- Request collections and environment variables
- Code generation and request recording
- Real time API monitoring
- Multi protocol support

### Installation
- **macOS**: Download.dmg file and drag to Applications
- **Windows**: Download.exe and run installer
- **Chrome**: Install from Web Store

### Security
All binaries are code signed and notarized (macOS Big Sur+)

Verify checksums: `sha256sum -c SHA256SUMS`
